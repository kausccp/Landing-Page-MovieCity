# 🎬 MovieCity

Uma landing page temática desenvolvida para apresentar uma seleção de filmes em uma interface moderna, visualmente atrativa e responsiva. O projeto foi criado com o objetivo de praticar o desenvolvimento de interfaces web utilizando React, CSS e componentes reutilizáveis.

## 📌 Sobre o projeto

O **MovieCity** é uma página inspirada em plataformas de entretenimento e streaming, com foco na apresentação visual de filmes e na organização dos elementos da interface.

O projeto utiliza uma identidade visual escura, destacando os cartazes dos filmes e proporcionando uma experiência de navegação simples e intuitiva.

## ✨ Funcionalidades

- 🎥 Apresentação de filmes por meio de cards visuais.
- 🧭 Menu de navegação com opções de Filmes, Categoria, Sobre e Contato.
- 📱 Menu adaptável para dispositivos móveis.
- 🔐 Botão de Login na área de navegação.
- 🎨 Interface com tema escuro e elementos visuais personalizados.
- 🧩 Organização do código em componentes React.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura da aplicação.
- **CSS3** — estilização, layout e responsividade.
- **JavaScript** — lógica e interatividade.
- **React** — criação de componentes e construção da interface.
- **Vite** — ambiente de desenvolvimento e ferramenta de build.
- **Git e GitHub** — versionamento e armazenamento do projeto.

## ⚙️ Como executar o projeto

### 1. Pré-requisitos

Antes de começar, instale o [Node.js](https://nodejs.org/) em seu computador.

### 2. Clone o repositório

```bash
git clone URL_DO_SEU_REPOSITORIO
```

Substitua `URL_DO_SEU_REPOSITORIO` pelo endereço do seu repositório no GitHub.

### 3. Acesse a pasta do projeto

```bash
cd landing_page_moviecity/01_landinpage
```

### 4. Instale as dependências

```bash
npm install
```

### 5. Execute a aplicação

```bash
npm run dev
```

Após executar o comando, acesse no navegador o endereço local exibido pelo Vite, geralmente `http://localhost:5173`.
